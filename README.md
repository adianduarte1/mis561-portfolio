MIS 561, Completed 10/01/2026, [A link to my published Tableau Story](https://public.tableau.com/views/PowerBITrainingCertifications_17906508439020/PowerBIStory?:language=en-US&publish=yes&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link). In Flex 4, I created the Margin % column on the Order Data sheet in my workbook. I calculated this value for each order by dividing the profit earned by the revenue earned. I would build this as a measure in Power BI that divides total profit by total revenue, so the overall margin percentage updates when someone filters by tier or segment. A calculated column would keep the margin percentage tied to each specific order, while the measure would show the margin for the selected group. With this change, Anita and Marcus could compare profitability themselves without asking me to create another Excel calculation for each group they wanted to examine.
